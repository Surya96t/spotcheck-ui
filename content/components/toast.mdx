## Usage

```tsx
import { ToastProvider, toast } from "@/components/spotcheck/toast"

// Wrap your app once.
<ToastProvider>{children}</ToastProvider>

// Then call it from anywhere.
toast.add({ title: "Saved", description: "support-qa is up to date." })
```

Screen readers hear each toast as it arrives.
