## Usage

```tsx
import { Composer } from "@/components/spotcheck/composer"

<Composer
  value={prompt}
  onValueChange={setPrompt}
  onSubmit={send}
  attachments={files}
  onRemove={removeFile}
  models={[{ value: "atlas-l", label: "atlas-l" }]}
  model={model}
  onModelChange={setModel}
  contextLimit={32000}
  usedTokens={3600}
/>
```

The meter estimates four characters per token for the draft. Pass real counts through `usedTokens`.
