## Usage

```tsx
import { Button, buttonClass } from "@/components/spotcheck/button"

<Button variant="ink">Deploy</Button>
<Button variant="accent">Run eval</Button>
<Button>Export CSV</Button>
<Button variant="ghost">Cancel</Button>

<Link href="/runs" className={buttonClass("ink")}>View runs</Link>
```

Use `buttonClass` to style a link as a button, so it stays a real link.
