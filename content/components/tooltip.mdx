## Usage

```tsx
import { Tooltip } from "@/components/spotcheck/tooltip"
import { Button } from "@/components/spotcheck/button"

<Tooltip content="Runs in the background">
  <Button>Queue run</Button>
</Tooltip>
```

Tooltips are for sighted pointer and keyboard users. They never appear on touch, and screen readers don't get the text, so give the control its own label and keep essential information out.
