## Usage

```tsx
import { DrawChart } from "@/components/ledger/draw-chart"

<DrawChart
  title="Answer accuracy, 14 weeks"
  label="Accuracy rose from 38% to 83% over 14 weeks"
  series={accuracy}
  max={90}
  ticks={[0, 30, 60, 90]}
  format={(value) => `${Math.round(value)}%`}
/>
```

It plays the first time it scrolls into view. Change its `key` to play it again.
