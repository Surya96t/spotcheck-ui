## Usage

```tsx
import { RunReceipt } from "@/components/ledger/run-receipt"

<RunReceipt
  title="Run R-2041"
  meta="atlas-l · 31 Oct 21:42"
  lines={[
    { label: "Input tokens", value: "2,140" },
    { label: "Output tokens", value: "412" },
    { label: "Tool calls", value: "5" },
  ]}
  total={{ label: "Total", value: "$0.0092" }}
/>
```

It prints the first time it scrolls into view. Change its `key` to print it again.
