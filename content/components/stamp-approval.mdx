## Usage

```tsx
import { StampApproval } from "@/components/spotcheck/stamp-approval"

<StampApproval
  call={{
    name: "send_email",
    args: { to: "finance@example.com", subject: "Q3 refund summary" },
    resolved: "Emails 41 refund rows to finance@example.com.",
    risk: "high",
  }}
  editable={["subject"]}
  onApprove={(args) => release(args)}
  onDeny={halt}
/>
```

Show what the call will really do in `resolved`, not just its arguments, because people rubber-stamp a bare Approve button. Mark an argument `editable` so someone can fix it without denying the whole call.
