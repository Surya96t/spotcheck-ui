## Usage

```tsx
"use client"

import { StreamResponse } from "@/components/ledger/stream-response"
import { useStream } from "@/hooks/use-stream"

export function Answer() {
  const { text, sources, status, error, start, stop, regenerate } = useStream("/api/chat")

  return (
    <StreamResponse
      text={text}
      sources={sources}
      status={status}
      error={error}
      onStop={stop}
      onRegenerate={() => regenerate()}
    />
  )
}
```

`useStream` reads the AI SDK's UI message stream with no `ai` package on the client. Return `createUIMessageStreamResponse` or `toUIMessageStreamResponse` from your route and it works. Anything else is read as plain SSE, where each `data:` line is more text.

Write `[1]` in the text to cite the first source. Screen readers hear one finished sentence at a time, not every token.
