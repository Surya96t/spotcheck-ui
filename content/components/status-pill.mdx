## Usage

```tsx
import { StatusPill } from "@/components/spotcheck/status-pill"

<StatusPill tone="ok">pass</StatusPill>
<StatusPill tone="warn">drift</StatusPill>
<StatusPill tone="bad">fail</StatusPill>
```

Always include a word, because colour alone doesn't reach everyone.
