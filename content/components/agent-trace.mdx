## Usage

```tsx
import { AgentTrace } from "@/components/spotcheck/agent-trace"

<AgentTrace steps={run.steps} live={run.status === "running"} />
```

Pass `ms` as an estimate for steps that haven't finished, so the progress bar has something to measure against.
