## Usage

```tsx
import { SwipeReview } from "@/components/spotcheck/swipe-review"

<SwipeReview items={queue} threshold={110} onAccept={markGood} onReject={markBad} />
```

The buttons do everything a drag does, so nobody needs to swipe. A vertical swipe still scrolls the page on phones.
