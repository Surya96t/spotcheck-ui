## Usage

Pass a number and it's formatted for you. Pass `text` for anything already formatted: digits roll
and every other character stays still.

```tsx
import { RollNumber } from "@/components/ledger/roll-number"

<RollNumber value={tokens} className="text-7xl" />
<RollNumber text="₹1,990" />
```

It inherits its size from the surrounding text, and it works in server components.
