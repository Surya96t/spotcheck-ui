## Usage

```tsx
import { TraceWaterfall } from "@/components/ledger/trace-waterfall"

<TraceWaterfall
  label="Support answer, 2.9 seconds in total"
  spans={[
    { id: "run", name: "agent.run", start: 0, end: 2900 },
    { id: "search", parent: "run", name: "search", start: 120, end: 760 },
  ]}
/>
```

Spans link through `parent`, and overlapping bars are work that ran in parallel.
