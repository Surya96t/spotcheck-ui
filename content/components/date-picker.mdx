## Usage

```tsx
import { Calendar, DatePicker } from "@/components/spotcheck/date-picker"

<DatePicker label="Billing starts" value={date} onValueChange={setDate} />
<Calendar value={date} onValueChange={setDate} />
```

Weeks start on Monday. Pass `locale` to change the language of the labels.
