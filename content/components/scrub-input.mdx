## Usage

```tsx
import { ScrubInput } from "@/components/ledger/scrub-input"

<ScrubInput label="Max tokens" value={tokens} onValueChange={setTokens} min={0} max={4000} step={50} />
```

Hold Shift while dragging to move ten steps at a time.
