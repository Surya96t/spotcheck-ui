## Usage

```tsx
import { HoldButton } from "@/components/spotcheck/hold-button"

<HoldButton duration={1200} onConfirm={deleteWorkspace}>Hold to delete</HoldButton>
```

Letting go early cancels. Once confirmed, screen readers hear "Confirmed" and pressing again resets it.
