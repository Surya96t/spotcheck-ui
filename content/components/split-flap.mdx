## Usage

```tsx
import { SplitFlap } from "@/components/ledger/split-flap"

<SplitFlap
  rows={jobs}
  width={22}
  columns={[{ label: "Job", start: 0 }, { label: "Target", start: 8 }]}
  accentCharacters={3}
/>
```

Pass new `rows` and only the cells that differ will spin. Keep the number of rows the same between updates.
