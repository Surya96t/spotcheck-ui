## Usage

```tsx
import { Sparkline } from "@/components/ledger/sparkline"

<Sparkline values={[30, 34, 33, 38, 41]} label="Requests rose from 30k to 41k" />
```

Leave out `label` when the numbers are already printed nearby, and it's hidden from screen readers.
