## Usage

```tsx
import { LedgerTable, type LedgerColumn } from "@/components/ledger/ledger-table"

const columns: LedgerColumn<Run>[] = [
  { key: "id", label: "Run", emphasis: true },
  { key: "score", label: "Score", numeric: true },
]

<LedgerTable title="Eval runs" rows={runs} columns={columns} rowKey="id" defaultSort={{ key: "score", dir: "desc" }} />
```

Sorting needs a client component, so a custom `render` has to come from one too. Define `columns` in a `"use client"` file.
