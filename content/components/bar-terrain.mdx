## Usage

Give it a height. It fills its parent's width, and colours come from your tokens.

```tsx
"use client"

import dynamic from "next/dynamic"

const BarTerrain = dynamic(
  () => import("@/components/spotcheck/bar-terrain").then((module) => module.BarTerrain),
  { ssr: false },
)

<BarTerrain className="h-96" label="Requests per hour across 30 regions" />
```

Load it with `dynamic` so three.js only downloads where it's used. The canvas is created as it
nears the viewport, pauses off screen and is removed when it's far away.

Set `label` to describe your data, because screen readers get that instead of the canvas. It also
replaces the canvas if WebGL fails or the browser drops it.

## Your own data

`source` returns the height of a bar at a grid position and a time in seconds.

```tsx
const source = (col: number, row: number, time: number) =>
  values[row][col] + Math.sin(time + col) * 0.1

<BarTerrain cols={24} rows={7} source={source} />
```

## As a background

Pass `camera` and `lookAt` for a wider view, `fade` to dissolve the far bars into the page, and
`peak` to turn the tallest bars the accent colour. `autoPick` lifts a bar every few seconds, and
`onPick` tells you where it is, so you can label it. `pauseWhenSlow` holds a still frame on a device
that can't keep up, so a large field doesn't make the page around it slow to respond.

```tsx
<BarTerrain
  cols={110}
  rows={64}
  camera={{ fov: 34, position: [10, 9.5, 21] }}
  lookAt={[4.5, 0.2, 0]}
  fade={{ near: 16, far: 52 }}
  peak={2.4}
  autoPick
  pauseWhenSlow
  onPick={(pick) => moveLabel(pick)}
  className="absolute inset-0 h-auto"
/>
```
