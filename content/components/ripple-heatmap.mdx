## Usage

```tsx
import { RippleHeatmap } from "@/components/ledger/ripple-heatmap"

<RippleHeatmap
  label="Requests per hour by weekday"
  values={perHour}
  rowLabels={["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"]}
  cellLabel={(cell) => `${cell.value} at ${cell.column}:00`}
  onPick={setFocus}
/>
```

`values` runs from 0 to 1, row by row. The whole grid is one tab stop, and arrow keys move inside it.
