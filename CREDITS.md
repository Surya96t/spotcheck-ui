## Fonts

All three are under the [SIL Open Font License 1.1](https://openfontlicense.org), installed through
Fontsource.

| Font | Designer | Used for |
|---|---|---|
| [Archivo](https://github.com/Omnibus-Type/Archivo) | Omnibus-Type | Display and body type, using its width axis |
| [IBM Plex Mono](https://github.com/IBM/plex) | IBM | Labels, code and figures |
| [Instrument Serif](https://github.com/Instrument/instrument-serif) | Instrument | Display type in the Folio skin |
